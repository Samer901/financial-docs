# التوثيقات المالية

تطبيق لإدارة توثيقات الرواتب لمشاريع فريق سوريانا الأمل: الكادر والعقود وجداول الدوام والرواتب وتجميع ملفات التوثيق.

- البيانات محفوظة في ملف `kadr-data.json` على Google Drive، ولا يُخزن شيء في هذا المستودع.
- التحديثات التي يجهزها Claude تُوضع في ملفات تبدأ بـ «تحديثات Claude» داخل مجلد «التوثيقات المالية»، والتطبيق يدمجها تلقائياً عند الفتح.
- الإعدادات في `config.js` (Client ID ومعرّف المجلد الرئيسي).
